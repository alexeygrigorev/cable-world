# Архитектура MVP

## Границы продукта

«Мир Троссов» начинается как локальное семейное приложение. Главный сценарий: открыть карту или список, выбрать объект, посмотреть карточку, отметить посещение и сохранить семейные материалы.

## Основные модули

- каталог объектов: название, тип, регион, координаты, описание, заметки;
- карта: слой OpenStreetMap/MapLibre, маркеры объектов, переход к карточке;
- карточка объекта: описание, координаты, статус посещения, фото и билеты;
- журнал посещений: дата, объект, заметка, вложения;
- локальное хранилище: SQLite на первом этапе;
- синхронизация: PocketBase позже, после стабилизации локальной модели.

## Текущий черновик

В текущем каркасе карта заменена списком демо-объектов, потому что нужно сначала закрепить форму данных и базовую навигацию. Это позволяет проверять интерфейс без сетевых ключей, нативных расширений и тяжелых зависимостей.

## Следующие технические решения

- выбрать Godot-плагин или тонкую интеграцию для MapLibre;
- описать SQLite-схему для объектов, посещений и вложений;
- добавить импорт исходного каталога из JSON;
- подключить GdUnit4 для сценариев интерфейса и доменной логики;
- вынести демо-данные из GDScript в ресурс или JSON, когда появится реальный каталог.
