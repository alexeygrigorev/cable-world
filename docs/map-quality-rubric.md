# Map Quality Rubric

Дата: 2026-05-31.

Эта рубрика нужна, чтобы не объявлять карту готовой по ощущению. Каждая итерация должна получить оценку по критериям ниже и пройти обязательные functional checks.

Reference target:

```text
/home/alexey/tmp/file_000000000d5c71f4b60ecae32dd4240b.png
```

Это не требование скопировать картинку буквально. Это направление: 16-bit RPG / pixel journey atlas, плотная читаемая карта, крупные горы и леса, ясные маршруты, транспортные станции как landmarks, теплая природная палитра.

## Gate Checks

Эти пункты обязательны. Если один из них не выполнен, оценка не может быть выше 6/10.

- Карта не растягивается под viewport. Географическая подложка сохраняет aspect ratio.
- Можно двигать карту мышью/тачем во все стороны, без ощущения, что она приклеена к экрану.
- Иконки объектов кликабельны.
- Drag по карте не ломается из-за маркеров.
- Стартовый экран содержит карту fullscreen и только минимальный map UI.
- Все объекты расположены по координатам, а не разложены декоративно.
- Иконка выбирается по нормализованному типу объекта, не через substring/`contains()`.
- Web build отдается локально с gzip для `.wasm`, `.pck`, `.js`.
- Города и ориентиры находятся в географически правдоподобных местах: Hamburg у северной низменности/воды, Rostock у Балтики, Dresden не съезжает в Чехию.
- Рельеф соответствует реальности: большие горы есть только там, где есть реальные горные массивы. Ограничения должны задаваться по конкретным географическим слоям/полигонам, а не общим правилом "север/юг": North German Plain не должен выглядеть как Альпы, но Норвегия на севере может и должна иметь горы.
- Озера и острова не декоративные: крупные озера должны соответствовать реальным водоемам, а важные острова вроде Rügen должны быть учтены в форме/композиции карты.

## Score Bands

### 1/10

Экран технически сломан: карта не открывается, маркеры не видны, есть runtime errors, Web build не грузится.

### 2/10

Карта открывается, но выглядит как placeholder или debug layer. UX не соответствует задаче: много лишнего UI, нет ощущения карты, маркеры мешают.

### 3/10

Текущий плохой baseline после первой попытки:

- карта fullscreen, но визуально похожа на простую GIS-схему;
- Германия заметно растянута под экран;
- горы и леса почти не читаются;
- картинка пустая и плоская;
- pan/click ощущаются ненадежно;
- стиль далек от reference target.

Это не acceptable result.

### 4/10

Технически стало лучше, но визуально все еще слабо:

- aspect ratio частично исправлен;
- маркеры кликаются;
- карта двигается;
- но подложка все еще пустая, без выразительных landmarks;
- горы/леса/города не создают RPG-atlas ощущение.

### 5/10

Рабочая карта без грубых UX багов:

- нет растяжения;
- есть pan/drag;
- маркеры кликабельны;
- есть базовые горы, леса, вода, маршруты;
- но композиция слабая, стиль неоднородный, хочется заменить картинку.

### 6/10

Приемлемый prototype:

- Германия выглядит географически нормально;
- рельеф и маршруты читаются на мобильном экране;
- маркеры не слипаются критично;
- карта уже usable;
- но до reference target далеко: объекты недостаточно отделены от фона, подписи/ориентиры слабые, карту приходится рассматривать слишком долго.

### 7/10

Хорошая рабочая версия:

- карта не растянута и приятно двигается;
- горы, леса, города, водоемы и маршруты видны без zoom;
- иконки consistent и достаточно крупные;
- mobile viewport выглядит аккуратно;
- web загрузка не раздражает;
- но еще есть заметные стилистические компромиссы или слабые зоны композиции.

### 8/10

Достойный результат, который можно показывать:

- с первого взгляда похоже на приключенческую карту, а не на GIS;
- карта визуально близка к reference target по плотности, палитре и читаемости;
- фон достаточно спокойный в местах интерактива, а иконки транспорта сразу заметны;
- Berlin, Hamburg, Rostock и основные горные ориентиры подписаны и помогают узнавать Германию;
- рельеф, крупные озера и важные острова географически узнаваемы и не выглядят случайными;
- aspect ratio правильный на mobile и landscape;
- pan/drag/click работают естественно;
- горы и леса являются сильными визуальными элементами;
- маршруты помогают читать карту, не превращая ее в схему метро;
- нет лишнего UI поверх карты.

Это минимальный уровень, где можно говорить "хорошо".

### 9/10

Очень сильный результат:

- карта выглядит цельно, как art-directed game map;
- все основные области Германии имеют характер: север, центр, Альпы, Рейн, Берлин/Бавария и т.д.;
- маркеры воспринимаются как часть карты, а не наклеенные картинки;
- zoom/pan сохраняют читабельность;
- нет заметных пустых зон, артефактов, растяжения, случайных линий или неуместных цветов;
- desktop/mobile/landscape screenshots все выглядят профессионально.

### 10/10

Лучшее, что реально можно сделать в рамках текущего проекта без полного отдельного production art budget:

- визуально хочется оставить именно эту карту;
- она уверенно напоминает reference target по качеству: 16-bit/RPG atlas, теплый мир, горы, леса, маршруты, landmarks;
- все interactive requirements работают без оговорок;
- рельеф, озера, острова, города и интерактивные объекты проверены на географическую точность, а не только на визуальную красоту;
- карта responsive, не растягивается, удобно двигается;
- loading optimized: gzip Web build, компактные runtime assets, нет лишних source sheets в `assets`;
- результат проверен скриншотами mobile + landscape + desktop и не имеет видимых проблем.

## Weighted Rubric

Итоговая оценка считается не математически жестко, но каждый блок должен быть явно оценен.

- Visual direction and art quality: 30%
- Geography, aspect ratio, and composition: 20%
- Relief, water, islands, and landmark accuracy are part of the geography score and can cap the final score if visibly wrong.
- Interaction: pan, drag, zoom, click: 20%
- Object placement and marker readability: 15%
- Performance and Web loading: 10%
- Documentation and repeatability: 5%

## Readability Checklist

Начиная с user review 2026-05-31, карту нельзя оценивать выше 7/10, если она не проходит визуальную читаемость:

- За 1-2 секунды понятно, что это Германия, а не абстрактная зеленая подложка.
- Главные ориентиры видны без поиска: Berlin, Hamburg, Rostock, Alpen/Zugspitze, Harz.
- Транспортные иконки отделяются от фона за счет ореола, тени или локального quiet zone.
- Фон не конкурирует с интерактивными объектами: детали есть, но под маркерами нет визуального шума.
- Подписи похожи на старую приключенческую карту: скорее Middle-earth/Heroes/Warcraft top-down, чем плоские GIS labels.
- На mobile screenshot можно быстро понять, где север/юг и где основные группы объектов.
- В городах с несколькими объектами показывается cluster/stack behavior, а не беспорядочная куча одинаковых значков.

## Iteration Protocol

После каждой заметной итерации надо записать:

- screenshot paths;
- score 1-10;
- что мешает следующему баллу;
- какие gate checks провалены;
- next action.

Оценку 10/10 можно ставить только после просмотра свежих screenshots и проверки interaction.
