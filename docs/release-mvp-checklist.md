# MVP-чеклист релиза APK

Этот чеклист нужен для ручной smoke-проверки семейного APK перед публикацией и после установки из GitHub Release. Он не заменяет автоматические тесты, а фиксирует минимальный пользовательский маршрут текущего MVP.

## Перед сборкой

- Убедиться, что `VERSION`, Android `version/name` и Android `version/code` согласованы: `python3 -m unittest discover -s tests`.
- Проверить, что GitHub Actions `Проверки` зеленый на ветке релиза.
- Собрать артефакты локально или через workflow `Релиз`: `scripts/export-release.sh "$(cat VERSION)"`.

## Где скачать APK

Опубликованный APK лежит в GitHub Release проекта: <https://github.com/alexeygrigorev/cable-world/releases>. В нужном релизе открыть блок `Assets` и скачать файл вида `mir-trossov-android-<version>.apk`.

Если релиз собирался вручную через GitHub Actions без tag, APK можно временно взять из workflow artifact `mir-trossov-<version>`, но публичной точкой для установки считается именно GitHub Release.

## Smoke test перед релизом

- Установить APK на Android-устройство или эмулятор как sideload APK.
- Запустить приложение и убедиться, что на устройстве видно имя «Мир Троссов».
- Проверить ориентацию: открыть переключатель «Ориентация», выбрать «Вертикальная», «Горизонтальная» и «Как в системе», убедиться, что экран не застревает в неправильном режиме.
- Открыть раздел «Карта»: должны быть видны локальные объекты, выбор объекта на карте должен обновлять выбранный объект.
- Открыть раздел «Список»: найти объекты Германии, включая канатные дороги, фуникулеры и подвесный транспорт.
- Открыть карточку любого объекта из Германии: должны быть видны название, страна, регион или город, координаты, описание и технические поля без внутренних терминов.
- Изменить статус посещения в карточке, закрыть и снова открыть объект, убедиться, что статус сохранился.
- Проверить блок «Работа объекта»: статус работы, дата проверки и источник должны отображаться отдельно от статуса посещения.
- Добавить запись о фото в карточке: должна появиться понятная строка о фотографии без показа внутреннего пути файла.
- Перейти между «Карта», «Список», «Карточка» и «Журнал» после изменения статуса и фото, убедиться, что приложение не падает и выбранный объект остается согласованным.

## Smoke test после релиза

- Скачать APK из опубликованного GitHub Release, а не из локальной папки `dist`.
- Установить APK поверх предыдущей версии `v0.1.x` без удаления приложения.
- Запустить приложение и повторить короткий маршрут: список объектов Германии, карточка объекта, смена статуса, добавление записи о фото, возврат на карту.
- Если установка поверх старой версии не проходит, не менять package id, keystore или миграции вручную в рамках релиза; сначала завести отдельную issue с симптомом и версией APK.
