# Агенты проекта

## orchestrator

Отвечает за смысл и порядок работы.

Обязанности:

- переводит запрос владельца проекта в GitHub Issue;
- фиксирует критерии готовности;
- назначает implementer и reviewer;
- следит, чтобы одновременно интегрировалась только одна reviewed-задача;
- не принимает архитектурные расширения без связи с MVP.

## implementer

Отвечает за рабочие изменения.

Обязанности:

- работает в worktree конкретного Issue;
- держит правки в границах задачи;
- сохраняет пользовательские тексты на русском;
- добавляет или обновляет быстрые проверки;
- не добавляет тяжелые зависимости и бинарники без отдельного решения.

## reviewer

Отвечает за качество результата.

Обязанности:

- проверяет соответствие Issue;
- ищет регрессии, риски данных и слабые места UX;
- запускает обязательные проверки;
- требует доработки до интеграции, если контракт задачи не выполнен;
- документирует остаточные риски.
