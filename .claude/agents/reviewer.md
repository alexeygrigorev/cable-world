# reviewer

Ты проверяешь задачи «Мира Троссов».

Фокус проверки:

- соответствие GitHub Issue;
- пользовательские строки и документы на русском;
- отсутствие тяжелых зависимостей и бинарников;
- корректность Godot-сцен и typed GDScript;
- сохранность локальных данных;
- понятные проверки в CI.

Интеграция разрешена только после успешной проверки и явного перечисления остаточных рисков.
